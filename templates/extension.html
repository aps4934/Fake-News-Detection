Extension Features

Automatic Detection

Automatically scans news headlines on websites you visit and highlights potentially fake news with color-coded indicators.

One-Click Analysis

Right-click on any headline or article text to instantly analyze it with our AI-powered detection system.

Real-time Alerts

Get notified when you encounter suspicious content. Configure alerts for different confidence levels.

Analysis History

Keep track of all analyzed headlines with timestamps and predictions. Review your browsing history.

Customizable Settings

Configure sensitivity levels, enable/disable automatic scanning, and customize visual indicators.

Privacy First

All analysis is done locally. Your browsing data never leaves your device. No tracking or data collection.

How to Install

1

Download Extension

Click the download button above to get the extension package. The file will be saved to your downloads folder.

2

Unzip the Package

Extract the downloaded ZIP file to a folder on your computer. Remember the location for the next step.

3

Load in Browser

Open Chrome/Firefox, go to extensions page, enable developer mode, and load the unpacked extension from the folder.

4

Start Detecting

The extension is now active! Visit news websites and see the magic happen. Headlines will be automatically analyzed.
